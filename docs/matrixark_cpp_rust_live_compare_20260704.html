Interpretation

C++ is much faster in this run, but the result should not be treated as final C++ superiority or final Rust regression until both sides use fresh same-commit release artifacts. The Rust artifact here is a debug bridge binary, and the raw write path is where the gap explodes first. The context correctness gate also failed because selected refs were empty.

The immediate next step is to rebuild both artifacts from the current commit in release mode, rerun the same bounded command, then only scale to 1K/10K/100K after selected refs are non-empty and parity evidence exists.
