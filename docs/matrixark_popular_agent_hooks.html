MatrixArk Hooks For Popular AI Agents

Date: 2026-06-24

Summary

MCP first:
  Codex, Claude, Cursor, Windsurf, Cline, Continue, vertical agents

Hook adapter:
  agents that expose lifecycle hooks or external command runners

tools/matrixark_agent_hook.py reads an agent JSON hook payload from stdin and normalizes it into MatrixArk MCP calls.

Universal Hook Command

cd /root/src/github-services/TemporalStore
echo '{"prompt":"Alice approved the GPU request.","session_id":"demo-thread"}' |
  python3 tools/matrixark_agent_hook.py \
    --agent generic \
    --event UserPromptSubmit \
    --backend local

Event Mapping

Before LLM / retrieve:
  UserPromptSubmit, before_llm, prompt, chat_prompt, session_start

After LLM / ingest:
  Stop, after_llm, assistant_message, response

Tool events / ingest:
  PreToolUse, PostToolUse, tool_call, tool_result, PermissionRequest

Commit events / one-pass batch extraction:
  Stop, SubagentStop, PostCompact, PreCompact, session_end,
  task_complete, idle_timeout

Agent Matrix

AgentBest MatrixArk integrationNotes
Codex Desktop / CLIMCP plus hook adapterMCP tools are explicit. Hooks can auto-capture prompt/tool/stop events when configured.
Claude DesktopMCPAdd MatrixArk as an MCP stdio server. Claude keeps local context and calls MatrixArk for durable context.
Claude Code-style agentsMCP plus native hook command where availableUse hook adapter for prompt/tool/stop/compact lifecycle events.
CursorMCP firstCursor keeps local code context and calls MatrixArk for team memory, runbooks, prior decisions, and skills.
WindsurfMCP first, external runner if availableUse the same MatrixArk MCP server; hook adapter works if the client can run external commands.
Cline / Roo-style agentsMCP firstThese loops are tool-heavy; MatrixArk should be a durable memory/tool provider.
ContinueMCP or HTTPGood fit for local IDE context plus MatrixArk durable memory.
GitHub Copilot-style agentsHTTP/MCP gatewayNative lifecycle hooks are not a stable public boundary; integrate through extension/server workflows.
Enterprise vertical agentsMCP, HTTP, and hooksBest target. They can send before-LLM, after-LLM, feedback, tool-result, idle, and commit events.

  },
  "metadata": {
    "source": "claude_hook",
    "agent": "claude",
    "agent_event": "UserPromptSubmit"
  },
  "agent_hook": {
    "source": "claude",
    "hook_type": "before_llm",
    "auto_captured": true
  }
}

Why MCP Still Matters

Not every popular agent exposes reliable lifecycle hooks. MCP gives a stable portable tool boundary. Hooks are best for automatic capture; MCP is best for agent-controlled retrieval and feedback.
