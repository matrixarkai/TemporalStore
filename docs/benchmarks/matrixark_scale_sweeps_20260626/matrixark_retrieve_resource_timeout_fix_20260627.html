## Code Fixes

- process-wide local JSONL read cache shared by short-lived adapters
- optional zero-copy local cache for synthetic scale runners
- retrieval scale runner uses telemetry-only visibility and disables recall reinforcement writes
- resource scale runner uses wait=false queued imports by default
- resource enqueue skips prior-context scan
- storage route validation enforces exactly one storage_family/write_mode path
- live C++/Rust adapters fail fast if requested storage_family is not configured

## Remaining Production Note

- 32-worker local JSONL retrieval is still high latency; production proof should use native C++/Rust prefix scan and batch append paths.
- Synchronous resource parsing/extraction remains available with --resource-wait but is intentionally not the default for large-resource scale tests.
