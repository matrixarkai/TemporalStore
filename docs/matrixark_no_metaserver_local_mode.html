MatrixArk No-Metaserver Local Mode

MatrixArk now supports an explicit local mode that does not start or require a metaserver. Set MATRIXARK_LOCAL_MODE=no-metaserver and the C++/Rust MCP wrappers use the temporalstore-local backend.

Why

Distributed TemporalStore still uses metaserver for table discovery, placement, partition ownership, multi-node operation, and Raft. Local MatrixArk development should not need that full cluster, so no-metaserver mode persists the same MatrixArk context records into a local record log.

Run It

cd 

MATRIXARK_LOCAL_MODE=no-metaserver \
MATRIXARK_TEMPORALSTORE_LOCAL_STORE=/tmp/matrixark-local-cpp.jsonl \
bash tools/matrixark_mcp_cpp_server.sh --line-json
python3 tools/matrixark_mcp_server.py \
  --backend temporalstore-local \
  --local-store /tmp/matrixark-local.jsonl \
  --line-json

Boundary

This gives MatrixArk no-metaserver local mode now. A true native C++ embedded single-node backend is still a future storage-engine task because the current C++ SDK requires metaserver address or consul before opening a table.
