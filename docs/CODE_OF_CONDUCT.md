# Code Of Conduct

This project expects respectful, technical, and good-faith collaboration.

Contributors should:

- be kind and professional
- assume good intent while still being precise about risks
- keep disagreements focused on the code, tests, and evidence
- avoid harassment, threats, personal attacks, and discriminatory language

Maintainers may remove comments, issues, pull requests, or access for behavior
that makes the project unsafe or unproductive.
