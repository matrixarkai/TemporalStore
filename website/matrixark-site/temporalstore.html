TemporalStore

Online temporal state for features, risk, and AI context.

TemporalStore is the MatrixArk engine for high-cardinality entity state that changes over time: rolling aggregates, filtered windows, distinct sets, long behavior sequences, frequency caps, and structured context.

Product Advantages

Why TemporalStore over a generic cache plus stream pipeline?

01

Temporal logic is native

Windowed counts, filtered aggregates, distinct sets, and sequences live inside the serving engine instead of being scattered across jobs and application code.

02

Lower pipeline complexity

Teams can serve many risk and feature policies directly from online state rather than building a new stream job and cache layout for every window.

03

High-cardinality friendly

The architecture is shaped around entity keys, model-aware objects, in-memory indexes, logs, and persisted pages for large online state.

04

Fresh online decisions

Risk, ads, recommendation, and agent systems can query recent state at request time instead of waiting for offline materialization.

System Architecture

Client SDK / API Router Partition worker Model engine WAL / oplog Page + index store

The core design is share-nothing by partition. A key is routed to one worker, the worker applies model-specific logic to hot object state, appends a replayable mutation log, and serves queries from memory, cache, or persisted pages.

Serving Workflow

  1. Ingest an event, counter update, profile change, or sequence append.
  2. Resolve namespace, table, data model, partition, and entity key.
  3. Apply updates inside the model instead of in a separate application layer.
  4. Answer arbitrary window, filter, aggregate, and sequence queries online.

Scenario Architecture

One serving path for event ingestion and feature reads.

Ingest

Application events, Kafka consumers, and batch repair jobs write the same entity timeline or aggregate object.

Store

Partition workers update hot objects, append logs, and maintain page/index state for replay and persistence.

Serve

Online systems request windows, filters, distinct counts, sequences, and latest profile state through one serving API.

Data Models

Built for temporal online decisions.

TemporalCounter

Counts and sums over keyed time buckets for velocity, caps, and online policies.

TemporalAggregate

Filtered sum, min, max, count, and model-specific rollups over recent event state.

TemporalDistinct

Unique merchant, device, campaign, IP, or session counts inside time windows.

Sequence

Recent behavior history, sorted timelines, long user action sequences, and inference features.

Hash/Profile

Latest user, item, merchant, campaign, or device state beside temporal features.

Context

Structured LLM and agent context, tool events, session memory, and safety counters.
