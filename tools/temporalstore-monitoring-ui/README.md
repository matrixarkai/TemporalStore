# TemporalStore Monitoring UI

Standalone mock console for TemporalStore operations and observability.

Open `index.html` directly in a browser. The current data source is `app.js`; later,
replace the mock arrays with calls to metaserver, data server, and benchmark APIs.

Covered views:

- Cluster overview
- Node level monitoring
- Partition and replica topology
- Diagnostics and trace samples
- Workload testing status
